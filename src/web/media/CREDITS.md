# Credits for the drone footage

All clips come from Wikimedia Commons. Each Commons file page shows a licence that allows reuse
and modification, and the licence has been verified: either a licence reviewer or bot confirmed it
against the original upload, or (CC0) a VimeoReview check confirmed it.

Changes made to all clips: trimmed to a 30-second excerpt, re-encoded to H.264 MP4
(libx264, CRF 26–28, yuv420p, faststart) and audio removed. The clips are then shown in the
console with synthetic static, signal tearing and telemetry overlays drawn on top.
